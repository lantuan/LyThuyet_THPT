# Ngân hàng đề động — Lý thuyết, Dạng toán, Bài tập
# Bộ sách: Kết nối tri thức với cuộc sống

## Cấu trúc thư mục

Mỗi khối lớp chứa các thư mục theo chương. Mỗi chương gồm 3 file:
- `LyThuyet` — Định nghĩa, định lý, công thức, giới hạn kiến thức
- `DangToan` — Các dạng bài, phương pháp giải, ví dụ mẫu
- `BaiTap`   — Bài tập có lời giải

## Ghi chú
- Tên thư mục dùng dấu gạch dưới, không dấu tiếng Việt.
- Mỗi thư mục luôn có đủ 3 file: `LyThuyet`, `DangToan`, `BaiTap`.
- Khi cần bài nào → tra bảng trên → vào đúng thư mục chứa bài đó.
- Nhiều bài trong cùng 1 chương → dùng chung 1 thư mục, nội dung được phân đoạn trong từng file.
